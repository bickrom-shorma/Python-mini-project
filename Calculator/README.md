
# 🧮 Simple Calculator Using Python

A beginner-friendly command-line calculator built using Python. This project performs basic mathematical operations using separate functions.

## 🚀 Features

This calculator supports 7 mathematical operations:

- **Addition (+)** – Adds two numbers.
- **Subtraction (-)** – Subtracts the second number from the first.
- **Multiplication (*)** – Multiplies two numbers.
- **Division (/)** – Divides the first number by the second.
- **Modulus (%)** – Returns the remainder.
- **Power (**)** – Calculates the power of a number.
- **Floor Division (//)** – Returns the quotient rounded down.
