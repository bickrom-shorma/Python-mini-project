# Digital Clock using Python and Tkinter

A simple digital clock created using Python and Tkinter.  
It displays the system's current time and updates automatically every second.

## Features

- Displays current system time
- Updates automatically every second
- Simple and clean GUI
- Beginner-friendly Python project

## Libraries Used

- `tkinter`
- `time`

> **Note:** Tkinter is usually included with Python, so you normally don't need to install it separately.
