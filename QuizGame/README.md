
# Python Quiz Game 🎮

A simple Python quiz game that tests basic computer hardware knowledge.

## Features
- 5 interactive questions
- Player name input
- Automatic score calculation
- Case-insensitive answer checking

## Technologies
- Python 3
- VS Code

## How to Run

```bash
python quiz_game.py
```

## Concepts Practiced
- Variables and data types
- User input and output
- If-else statements
- String methods
- Basic arithmetic
